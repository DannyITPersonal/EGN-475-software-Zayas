
# Café Calle Ocho Ordering System

## Project Option
**Option A: Café Calle Ocho — Little Havana**

## Project Overview
Café Calle Ocho is a Cuban café ordering system prototype designed to help customers place orders and help kitchen staff manage preparation.

## Problem Statement
Café Calle Ocho needs a clear way to organize customer orders and communicate their progress. Manual or disconnected ordering methods can create confusion for customers and kitchen staff. This prototype will provide a digital menu, order placement, a kitchen order board, order history, and menu administration so customers can order more easily and employees can manage orders efficiently.

## Target Users

### Sofia Rodriguez — Customer
- **Goals:** View the menu, order quickly, and check order progress.
- **Frustrations:** Waiting in line and not knowing when an order will be ready.
- **Technology comfort:** High.
- **Quote:** "I want to order my café con leche and breakfast without wasting time before work."

### Carlos Martinez — Kitchen Staff
- **Goals:** View incoming orders, organize preparation, and update order statuses.
- **Frustrations:** Keeping track of multiple orders during busy periods.
- **Technology comfort:** Moderate.
- **Quote:** "If I can see every order and its status on one screen, I can focus on making the food correctly."

## Must-Have Features
1. Digital menu with item descriptions, prices, and availability.
2. Customer order placement with item quantities.
3. Order confirmation with an order number.
4. Kitchen order board.
5. Order statuses: received, preparing, ready, and picked up.
6. Order history.
7. Menu administration for authorized staff.
8. Order modification and cancellation

## Out of Scope
1. Online payments.
2. SMS or push notifications.
3. Loyalty points and rewards.
4. Delivery and driver tracking.
5. Native Android or iOS application.
6. Third-party delivery integrations.

## Project Goal
Build a working web prototype that demonstrates the main customer ordering and kitchen order-management workflow.
